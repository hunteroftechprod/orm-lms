# Модель и структура приложения

Сборка Maven, Spring Boot, Spring Data JPA, Hibernate и PostgreSQL. Исходники находятся в `src/main/java/com/example/lms`.

| Блок | JPA-сущности | Ответственность |
|---|---|---|
| Пользователи | `User`, `Profile` | Роль и уникальная почта, профиль один к одному |
| Каталог | `Course`, `Category`, `Tag`, `CourseReview` | Категории, преподаватель, теги через `course_tag`, отзывы об обучении |
| Программа | `Module`, `Lesson` | Модули в порядке `orderIndex`, материалы урока и необязательное время занятия |
| Обучение | `Enrollment`, `Assignment`, `Submission` | Статус записи, задания, уникальная работа студента на задание и оценка |
| Проверка знаний | `Quiz`, `Question`, `AnswerOption`, `QuizSubmission` | Вопросы с одним или несколькими ответами, подсчёт и история результатов |

Всего 15 сущностей. `Enrollment` связывает студента и курс двумя внешними ключами и хранит дату и статус. `course_tag` реализует прямую связь многие ко многим. Коллекции загружаются лениво. Они преобразуются в DTO внутри транзакции там, где API возвращает содержимое коллекций. При списке курсов теги загружаются явным запросом, а при списке вопросов варианты подгружаются через `@EntityGraph`.

| Пакет | Назначение |
|---|---|
| `model` | Сущности JPA, связи, ограничения |
| `repository` | Репозитории Spring Data и целевые запросы |
| `service` | Транзакции, бизнес-правила и подсчёт результатов |
| `dto`, `mapper` | HTTP-контракты, валидация и преобразование объектов |
| `web` | REST-маршруты и общий обработчик ошибок |
| `config` | Учебная аутентификация и начальные данные |

Тесты лежат в `src/test`. Один PostgreSQL-контейнер живёт в течение тестовой JVM. Разные типы Spring-контекстов используют разные схемы.
